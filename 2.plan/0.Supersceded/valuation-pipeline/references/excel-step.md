# Excel step (fallback, only when the RECALC step failed)

1. Download `<draft>.xlsx`.
2. Open it in desktop Excel (not the browser preview). If a yellow bar appears, click Enable Editing.
3. Wait until the status bar no longer says "Calculating". If calculation is set to Manual,
   press Ctrl+Alt+F9.
4. Save (Ctrl+S). Keep the .xlsx format and the same file name.
5. Upload the saved file here.

Do not change any cell. If Excel shows a message about external links, choose "Don't update";
the check will report external links separately.
