A

Set up a company

Once per company. Takes about 15 minutes.

  1. AttachThe background files you have

    1–2 of the most recent valuation workbooks, and/or recent monthly financials and a balance sheet. Add the cap table if it's a separate file.

  2. TypeAsk the agent to set it up
    Set up Opus. These are our past valuations and financials.
  3. AgentReads every file and writes the company's methodology note

    Company rules are taken from the workbooks and cited. Anything the files don't show uses the firm's defaults.

  4. DecideAnswer its open questions
    For Opus, "IC Model" means the investment committee model.

    Answered once, remembered for every future quarter.

  5. ExcelSave the original files in the company folder

    The agent checks and reminds you if something isn't there.

No valuation workbook yet?

For a brand-new investment, build the first valuation the usual way (for example from the entry model). The agent's company note shows which firm defaults apply.

Then: Attach the finished workbook and type First valuation for Opus, 2026_Q3. It becomes the baseline for next quarter.

B

Add a monthly file

Whenever a monthly pack or balance sheet arrives.

  1. AttachThe new file, as you received it

    Monthly financials, a balance sheet, or supporting files: adjustment support, a cap table update, a comps export.

  2. TypeSay which company, plus anything unusual
    New file for Opus. New file for Opus. February was restated.
  3. AgentChecks, reads and saves the numbers

    Spots duplicates, new versions and layout changes. Reads actual months only, never budget. Flags anything that doesn't add up.

  4. DecideIf it says the file isn't in the company folder

    Save it there, then:

    Saved — recheck filing for Opus.

Tip

Send each month as it arrives. Quarter end is then a single message.

Mention it if

  • a month was restated
  • the pack now includes an acquired business
  • the file is a draft
C

Prepare the quarter

At quarter end. Use the quarter format YYYY_Q#.

  1. TypeStart the quarter
    Prepare Opus 2026_Q3.
  2. DecideGive your heads-up, or say none
    We acquired DEF on 15 August — include it pro forma.

    For each item it asks: this quarter only, or all future quarters? This is your one chance to steer before the review.

  3. DecideIf something is missing, attach it

    It names exactly what it needs, e.g. "September financials" or "pro forma support for DEF". Attach them and it carries on.

  4. AgentBuilds the review pack and inputs workbook

    Picks the right files, applies the methodology (firm → company → quarter → your notes), runs the checks and lists every file used or ignored.

  5. ExcelDownload the inputs and update the valuation workbook

    Every input shows the file and cell it came from.

  6. ComingThe agent rolls the workbook forward for you

Heads-up checklist

  • Acquisitions or disposals (with dates)
  • A change in how something is calculated
  • One-off or non-recurring items
  • Changes in ownership or the cap table
  • New entities or currencies

Nothing to report? Just say none.

D

Review and finalize

One conversation. Nothing changes until you confirm it.

  1. TypeOpen the review
    Review Opus 2026_Q3.
  2. TypeAsk anything about the numbers
    Why did EBITDA drop in August?
  3. TypeMake changes
    August revenue should be 1,240 — it was restated. Accept adjustment a2, it recurs. Reject a3. Flag f4 is fine — timing of a one-off payment.

    It repeats each change back and asks: this quarter only, or all future quarters?

  4. TypeApply the changes
    Apply.

    You get an updated pack and inputs workbook. Repeat steps 2–4 as needed.

  5. DecideFinalize and confirm
    Finalize Opus 2026_Q3.

    Any open high-priority flags must be acknowledged. Company-wide changes carry into next quarter automatically.

Types of change

  • A number: say the new value and why
  • A method: e.g. "use 11.5x"
  • An adjustment: accept, reject or change the amount
  • A flag: explain why it's fine

Changed your mind after finalizing? Ask to reopen the quarter.

E

LP report data

After the valuation workbook is final.

  1. ExcelFinish the valuation workbook with the final inputs
  2. AttachThe final valuation workbook
    Final valuation for Opus 2026_Q3 — LP report data.

    This also becomes next quarter's starting point.

  3. ComingThe agent returns the LP report data table

    Enterprise value, equity value, fair value of the fund's stake, implied multiple, quarter-on-quarter change, key metrics, and methodology changes with the reasons.

  4. ComingA drafted LP report section

What goes to the LP report

  • Headline values and the change since last quarter
  • LTM revenue and EBITDA
  • What changed in method, and why
  • Notable one-offs or acquisitions
F

Quick questions

Any time. No files needed.

  1. TypeFiles received
    What files do we have for OceanSight?
  2. TypeWhere a quarter stands
    What's the status of Opus 2026_Q3?
  3. TypeHow a company is valued
    What's Opus's methodology, and what changed this year?

The agent won't

  • change, move or delete your files
  • calculate or approve the valuation
  • make up a number it can't find

Always include

  • The company name
  • The quarter, as YYYY_Q# (e.g. 2026_Q3)
  • Whether a change is for this quarter only or going forward

Easiest habits

  • One company per chat
  • Send monthly files as they arrive
  • Keep originals in the company folder

If something looks wrong

  • Ask it where a number came from — every value has a file and cell
  • Correct it at review; the original is kept alongside
  • Still stuck? Tell the agent owner
